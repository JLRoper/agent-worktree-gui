⚠ waiting on you
Live over SSE: each worktree refreshes on its own cadence — cheap fields every 5s, merge verdict / PR / commit detail every 60s. Rows flash when something changed. Read-only for git: every scan is an inspect (rev-parse / rev-list / merge-base / cherry / diff / status / log). Only fetch touches refs. Spawning writes: a new worktree + branch under .worktrees/ (git worktree add -b wtgui/…), and the agent runs in that tree through the Hermes gateway — no child process, no API key handed to one. Projects: every git repo under scanRoots in config.json, grouped in a folder accordion per root (a project outside every root gets its own sibling folder), ordered by most recent activity. The green + beside a project name aims the spawn card at that project. Config: config.json — scanRoots, projects, cadences, dormantSeconds, host (loopback by default).
