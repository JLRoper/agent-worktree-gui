3. The pin: the multiset of the sheets that exist today

tools/css-split-pin.txt is written by measurement, never typed: one line per rule, at-rule context|selector|declarations exactly as the gate's parser normalizes it, grouped under a ## <sheet> header in load order and sorted inside each sheet. It is the multiset itself rather than a digest, for two reasons: a re-pin is a readable diff that names the rules a row changed, and a failure names the rule it lost. The header states the counts and the parser refuses a file whose lines disagree with it, so a truncated pin cannot be read as a shorter one.
