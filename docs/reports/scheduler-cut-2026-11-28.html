The one added statement

A derived class constructor must call super() before it reads this. The first cut-1 test run found it: 34 of 71 tests failed with ReferenceError: Must call super constructor in derived class before accessing 'this'. The fix is the one call at the top of the constructor, and it is the only statement either cut adds to a body:

    // The lifecycle layer is a prototype layer, not a state holder: every field the instance reads is
    // still set here, and the base constructor has nothing to do. Required by `extends`, nothing else.
    super();

The base has no such failure because the construct does not exist there; it is a property of the cut, not a defect the base shares.

6. What this page did not do

  • No version bump. The package stays at 1.197.0.
  • No push and no pull request. The branch merges into the turnover locally; the turnover branch is where the work rolls up and the reader decides when it lands.
  • No full suite run. The row's proof is the focused set above; the full suite is a landing gate, not this cut's.
  • No behaviour change is claimed. The two files hold the same method bodies the base held; the tests are the evidence that the panel still builds a scheduler and drives it.
