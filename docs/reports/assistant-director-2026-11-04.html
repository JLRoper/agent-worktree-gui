The charter is a new document, not the manager's file

The existing manager role is 19,773 characters and is the reader's own charter copied byte for byte. The Director's file is a different operating brief: the 20-minute order of the pass, the three cross-queue conditions (a running row with no live job, a row parked past an hour, a queued row nobody started), the two action lines, the routing order, and a boundary list that says never write a SPAWN line and never reply to a worker. It sits at 15,617 characters, leaving room for the changelog the panel appends.

The tab itself

How the wake is wired

  • One clock, not two. wakeEveryMinutes: 20 is written into the assistant's profile when it is created from the role. The panel's existing sentry calls checkCadence() on the same pass that runs the queue failsafe; there is no second setInterval, no panel-wide timer, and a live turn of that assistant is the clock.
  • An event, not a sweep. The cadence is exempt from the hourly sweep budget, which exists for conditions a later pass can re-raise. A standing pass that is refused is a pass that did not happen; the interval itself is the throttle.
  • Exact delivery. The wake ladder normally moves a wake off a failed assistant; a cadence wake is delivered to the assistant that carries the interval, so a failed last turn cannot turn the Director's pass into Assistant #1's.
  • Idempotent registration. A fresh roles.json seeds both built-ins; a store written before the Director existed gets it appended by id exactly once; a reader's edit under the same id is never regenerated.

The two powers, and the boundaries around them

LineWhat the panel doesWho may write it
QUEUE <assistant> | <row>Adds a queued row to that assistant's queue, recording the Director as createdBy.Assistant Director only; every other role is refused by name.
MESSAGE <assistant> | <text>Starts a turn on that assistant's own thread with the text; a live thread refuses rather than stacking.Assistant Director only.
TO <thread>:Replies to a worker.Refused for the Director; the worker belongs to its assistant.
SPAWN …Cuts a worktree and starts a worker.Refused by the Director's spawn: "off" profile and withheld from its grammar.
RESTART …Queues a panel/gateway restart.Refused for the Director; a restart would kill the turn reading the reply.
