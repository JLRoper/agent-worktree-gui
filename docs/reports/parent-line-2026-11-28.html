1. The five sayings, and what decides each

The line is one sentence plus a provenance, and the provenance is the point: a sentence that reads "cut from X" whether X came from the panel's own cut book or from a reconstruction of a branch nobody watched is the defect this replaces. Each saying is a separate kind, so a renderer, a test and this page can name the same case instead of matching on prose.

kindthe exact linedecided by
recordedcut from <branch>the cut book has the tree, through recordedParentFor; the title names the key the record sits under
reconstructedcut from <branch> - reconstructed from its reflog, not recordedno cut record, and the parent book says backfilled. A guess from the shared-ticket heuristic says reconstructed, not recorded (its title names which reconstruction)
unknownunknown - no cut record and its reflog names no local branchneither source answers; the title carries the reason, including a tie between two equally near candidates
basecut from the project base <branch> - <branch> is the turnover destination, never a child's parentthe record (or a refused reflog) names main, master, trunk or develop
turnoverturnover container - nothing above itthe row IS the project's turnover branch, read from the project's own turnover list

A row that is the project's own checkout carries no line at all: it IS the base. That is one delete row.parentLine in server.js:4780's overlay, and nothing else in the snapshot chain drops the field.

3. What the module refuses, in the same words

  • A guess is never printed as a record. parentSource: "backfilled" yields kind: "reconstructed" and a sentence that says so; there is no branch of parentLineFor that turns a backfilled answer into "cut from X" alone.
  • A sibling is never printed as a parent. A cut record that names the tree's own branch is not a parent (the module falls through to unknown), and a reconstruction that names it is refused the same way. lib/parents.js has already refused the descendant and equal-tip shapes before a parent reaches the module.
  • A tie reads unknown. pickBackfill answers null when two ancestors are equally near, and the line is the unknown sentence with ambiguous: ... in its title - never a coin flip between siblings.
  • Main and master are never a parent. isMainName covers main, master, trunk, develop and the project's own mainBranch; every one of them lands on the base saying. A reflog that refused a main name now carries that fact (refused, lib/parents.js:205) instead of a sentence being parsed back into a branch name.

4. Where the facts come from, and what it costs

The row already carried row.parent and row.parentSource from the scan, which is the parent book's answer; it could not say how sure that answer is, or name the record behind it. server.js:4780 withParentLines stamps the sentence on each row from one read of the cut book per snapshot (jobs.loadParents(), the same 500-record book withTreeKinds already walks per row), plus one Map lookup in the parent book for the reason. The page never reads a file: it draws row.parentLine.

The page's template and the proof's renderer cannot drift: public/board-scaffold.js is a classic script and cannot import lib/parent-line.js, so test/parent-line.test.js pins the page's literal template to parentLineItemHtml's markup, its .dim label and .mono value, and asserts that no stylesheet rule names .git-parent anywhere in the panel's sheets.
