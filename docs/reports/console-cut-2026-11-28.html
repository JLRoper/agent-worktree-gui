3. Why a classic script has no re-export line

public/board/console.js is not an ES module: public/index.html loads it as a plain script, and so it loads the four cut files too, after it and before app.js. In a classic script a top-level function IS a property of window under its own name, and a top-level const/let a binding in the page's one global lexical environment, which app.js reads by bare name. Moving a declaration to another classic script changes the file it is written in and nothing about the name the page reads, so there is no import/export line to add and no call site to touch. The entry point's header is the re-export this shape allows: it names the five files and the load order, and the proof below is what makes it more than a comment.
