How the qualifying set was recomputed

For every directory under .worktrees that git worktree list --porcelain registers, the sweep re-read four facts at the moment of deletion, in this order, and stopped at the first that failed:

  1. Is it live? The tree's path against the live job set (~/.wag/state/jobs.json plus the running panel's /api/jobs, statuses running, starting, waiting, waiting_for_approval, queued) and against an open PR on its branch.
  2. Is it clean? git status --porcelain in the tree, counted, not inspected. 7 trees failed at this check.
  3. Is every commit's patch in main? git cherry origin/main HEAD, plus lines counted. This is the authority that survives a rebase landing, where the branch tip is never an ancestor of main.
  4. Is the work landed? git rev-list --count origin/main..HEAD above zero with no plus lines, or zero with the tip contained in origin/main.
One reading decision, stated so a reader can disagree with it. The brief qualifies a tree on "count above zero, or MERGED per its PR with content on main". A tree whose branch sits at zero commits ahead of origin/main satisfies neither leg literally, but it also holds nothing that could be unlanded: its tip is contained in origin/main, so every object it names is already on main, and git cherry prints nothing at all. 11 of the 27 removed trees had a MERGED PR on their branch, 4 of them merging exactly the head the tree still carried; the other 16 had no PR at all and were cut trees that produced no commit, still standing at their cut point. All 27 were counted as landed by containment, which is the only leg that applies to them, and the evidence column of the removed table says so per row. Nothing with a commit main does not carry was removed, and nothing dirty was removed.

Two trees were held because their PR is OPEN (#468, #462) even though they are clean, and one was held because one of its commits has an added line absent from main while its PR is CLOSED rather than MERGED (#607). Both readings come from gh pr list --state all for the clone, 400 rows: 389 MERGED, 9 CLOSED, 2 OPEN.
