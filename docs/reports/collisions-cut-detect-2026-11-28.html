Row 507: the collision detector leaves lib/collisions.js, and every name it exported still comes from that path

Cut one of two for the module-separation report's entry #11 - 1,149 lines moved into lib/collision-detect.js behind the 57 names lib/collisions.js has always exported.

Done. The detection half of lib/collisions.js - the vocabulary, the rules, the reason, the version line, the detection itself, the COLLISION line and the merge question - is now lib/collision-detect.js. lib/collisions.js keeps the store (CollisionBook, countStates, and the three private readers that shape a record) and re-exports all 55 detection names from ./collision-detect.js, so no import site moved. The module's export set, read off the running module, is the same 57 names before and after. The card's ranges were re-measured on this base, and its boundary moved one function and two helpers: oldAbsence, normSidesOf and nowIso stay with the store, because the store is their only caller. No behaviour change, no version bump, no push, no pull request.
