The method, in one paragraph. A module's DOM is found by the class tokens its source writes: class="..." values, className assignments, classList.add/remove/toggle arguments and setAttribute("class", ...). The reader strips comments first, and it walks template literals with a scanner rather than a regex, so a state class chosen inside an expression (class="init-card${open ? "" : " is-titlecard"}") counts and const cls = `badge ${...}` is resolved one level. A token written by exactly one producer is that producer's private token. A rule is that producer's rule when the first class in one of its selector entries is one of its private tokens - the structural class, not every token, so .as-task.is-done stays the task card's rule even though the is-done modifier is written by someone else. The sheet with the most private rules is the module's owner; every other sheet with at least one is a surface the module spans.

What the method cannot see

A class built from a value the tool cannot resolve is counted as dynamic, never guessed. The class set is read from source, not from a running page, so a class that only the server or a test fixture writes is invisible, and a class a module writes but never renders still counts. The page was not booted for this row: the browser proof that the sheets themselves render is docs/reports/css-split-review-2026-11-28.html (dead selectors measured against a fixture), and this report does not restate it. The tool is committed and the command is in section 10, so every number here can be re-read.

8. The plan: the cuts whose seams disagree, ranked

Ordered by how many rules move out of a sheet that is not the module's, with the cheapest first among equals. Each entry names what a cut would need, not what it would look like afterwards.

1. public/assistant.js - four cuts, 290 rules outside its owner

9,622 lines, 310 private tokens, owner initiatives.css 272 (48.4%). Spans pipeline.css 92, panes.css 70, assistant-panes.css 67, assistant.css 45, queue.css 9, console.css 3, core/task-card.css 3, chrome.css 1.

What it would need.
