1. What moved, and what stayed

The brief was one cut of the module-separation plan: take the restart checks out of lib/restart.js into lib/restart-checks.js, a pure move, with lib/restart.js re-exporting every name it loses so no caller changes. The plan's entry 16 splits the file in two; this row is the checks half only, and the controller stays where it is.

What went to the new file, with the line each unit now sits on:

  • lib/restart-checks.js:20 PROOF_PROMPT, the token the proof turn must answer;
  • :24 PROVIDER_KEY_NAMES, the credential names the provider key check looks for;
  • :29 TERMINAL_RUN, :32 MAX_CONSUMED, :33 sleep, :34 nowIso, :35 clip: the five small helpers both halves read (module-private before the cut);
  • :43 servedVersionFromDisk, :53 versionParts, :58 compareVersions, :66 sameVersion, :72 versionsNamed: the version half;
  • :77 RESTART_SHAPE, :82 REASON_REQUIRED, :88 NEVER_CHANGED_REASON: the sentences a refusal or a failed restart is recorded with;
  • :99 gatewayLaunchPlan, :121 restartFilePath, :125 gatewayRestartLogPath: where a restart is started from and recorded;
  • :133 providerKeyCheck, the one check that runs before anything is stopped;
  • :181 proveGatewayTurn, the one real turn that settles whether a restart happened.

What stayed: the controller and its record. lib/restart.js:80 RestartController still owns the queue, the one-shot ledger (consumed), the wait, the gateway restart and its pid guard, the stop-and-start fallback, the panel replacement, the resume and the single wake. The gateway identity re-export stays at lib/restart.js:76: it is a re-export of lib/hermes-runtime.js and no code moved with it, so moving the statement would have been change without a reason.

Two directions follow from that. The checks import nothing from the controller (lib/restart-checks.js:12-15 imports only node:fs, node:path, ./hermes-config.js and ./paths.js), and the controller imports back the eighteen names it still reads at lib/restart.js:54. The five helpers are exported by the new file for that import and are not re-exported: they were module-private before the cut, so putting them on lib/restart.js's surface would have added names the module never had. This is the direction rows 509 and 510 used for clip, isObject and noneGate.

The one name the plan's range left behind

The plan's card starts the new file at lib/restart.js:54, which leaves PROOF_PROMPT at line 50 in the parent. The proof turn defaults to it (prompt = PROOF_PROMPT), so that arrangement would have made restart-checks.js import restart.js while restart.js imports restart-checks.js. The constant moved with the turn instead, four lines above the card's range, and is re-exported with the rest. It is the only name that moved outside the card's range, and it is why this cut has one direction rather than a cycle.
