On lanes

How this was measured

git archive <sha> | tar -x -C <dir> for each end, then wc -l over server.js, lib/**/*.js, public/**/*.js|css|html; grep -cE '^(async )?function |^const [A-Za-z_$][A-Za-z0-9_$]* = (async )?\(' for top-level declarations; grep -cE '^ [A-Za-z_$][A-Za-z0-9_$]*\(' for method lines on lib/assistant.js and lib/jobs.js; grep -ohE '"/api/[a-z0-9/:-]+"' server.js routes/*.js | sort -u for routes. Counts include comments and blank lines. test/ is measured separately (60,032 lines) because it is not shipped and does not create lanes on the page. Module counts are the file counts of the seven directories in the split table, one directory each, no recursion past the directory.
