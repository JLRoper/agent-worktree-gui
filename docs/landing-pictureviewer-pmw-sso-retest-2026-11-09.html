6. MFA handoff

What the reader had to do, and where: after the gateway redirected the browser to Okta (client 0oa215mlw50fRgSFR1d8, application "SEFL Webapp Login Gateway - test2"), the run selected the "Get a push notification" factor and stopped on the Okta "Push notification sent" screen with the username ROPER. Approving the Okta Verify push on the phone enrolled for ROPER completed each hop. Three pushes were approved; the first landing came 67 seconds after the push was sent, the second and third within a minute.

If this is run again: no code or password is typed by the agent. Start the walk, wait for the Okta page titled "Connecting to Sign in with your account", and approve the push when the phone buzzes. If the push expires the run parks on Okta's "Push notification sent" screen and reports PUSH_TIMEOUT; the browser session is then dead and a fresh run needs a new push.
